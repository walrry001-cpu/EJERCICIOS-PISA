# Reto matemático: La misión de las fracciones cajamarquinas

Aplicación educativa interactiva para practicar fracciones impropias y equivalentes con situaciones inspiradas en la provincia de Cajamarca, Perú.

## Archivos del paquete

- `index.html`: sitio interactivo autocontenido. **Todas las imágenes están incrustadas dentro del propio HTML en formato Base64**, así que no necesita una carpeta `assets` ni enlaces de imágenes externos.
- `.nojekyll`: archivo auxiliar para GitHub Pages.

## Cómo abrirlo

Abre `index.html` con Chrome, Firefox, Edge o cualquier navegador moderno. No necesita instalación ni conexión a internet después de descargarlo.

## Cómo publicarlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `.nojekyll` a la raíz del repositorio.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/(root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio y abre la dirección que te indique.

## Sobre caché

Este proyecto no depende de imágenes externas ni de archivos en carpetas separadas, lo que evita errores por rutas de imágenes. No es posible borrar la caché de los navegadores de los estudiantes desde el archivo ZIP; si GitHub muestra una versión antigua tras actualizarlo, recarga la página o prueba una ventana privada.
